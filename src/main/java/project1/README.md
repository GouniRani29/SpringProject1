# 🎓 Spring Boot Student CRUD Application

## 📌 Project Overview

This project is a Student Management System developed using Spring Boot. It performs CRUD (Create, Read, Update, Delete) operations using REST APIs and stores data in MySQL.

---

## 🚀 Technologies Used

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- REST API
- Postman

---

## 📂 Project Structure

src
 ├── Controller
 ├── Service
 ├── Repository
 ├── Entity
 ├── Exception
 └── Resources

---

## ✨ Features

- Add Student
- View All Students
- View Student By ID
- Update Student
- Delete Student
- Exception Handling

---

## REST APIs

### Create Student

POST /students

### Get All Students

GET /students

### Get Student By ID

GET /students/{id}

### Update Student
